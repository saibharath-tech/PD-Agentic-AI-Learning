# PD-Agentic-AI-Learning
A structured learning and project repository focused on Python, Agentic AI, Machine Learning, RAG, LangGraph, and VLSI Physical Design automation. The goal is to build AI-powered assistants for timing analysis, TCL generation, report analysis, and semiconductor design workflows.

**Overview**

This repository documents my journey of learning and implementing Agentic AI, Machine Learning, and Large Language Model (LLM) technologies with a strong focus on VLSI Physical Design applications.

As a Physical Design Engineer, I believe the future of semiconductor design will increasingly involve AI-assisted automation, intelligent design analysis, and agent-based engineering workflows. The primary objective of this repository is to bridge the gap between traditional Physical Design methodologies and modern AI technologies.

The repository contains structured learning materials, Python implementations, practical exercises, mini-projects, and end-to-end applications related to:

Python Programming
Machine Learning Fundamentals
Large Language Models (LLMs)
Retrieval-Augmented Generation (RAG)
LangChain
LangGraph
Agentic AI Systems
Physical Design Automation
Timing Analysis Assistants
TCL Script Generation
Semiconductor Knowledge Assistants

The long-term goal is to build an AI-powered Physical Design Copilot capable of assisting engineers with:

Timing report analysis
Setup and hold violation debugging
Congestion analysis
Clock Tree Synthesis insights
ECO recommendation generation
TCL script automation
Physical Design methodology assistance
Documentation search using RAG

Through this repository, I aim to develop practical expertise in combining semiconductor domain knowledge with AI technologies to create intelligent engineering tools that improve productivity, accelerate debug cycles, and enhance design closure efficiency.

All learning activities, projects, code samples, and experiments will be version-controlled and documented here as part of a continuous learning journey toward becoming a Physical Design Engineer with Agentic AI expertise.

This repository serves as both a personal knowledge base and a portfolio demonstrating the integration of AI-driven solutions within VLSI Physical Design workflows.
